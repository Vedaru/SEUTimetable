# SEU Timetable

SEU Timetable 是一款专为东南大学（SEU）学生设计的开源课表工具。它通过模拟登录教务处系统，实现课表的一键导入，并提供响应式的桌面挂件与优雅的 UI 体验。

# 功能特性

1. 智能导入：内置解析脚本，一键抓取全学期课表。
2. 现代 UI：基于 Jetpack Compose 构建，遵循 Material 3 设计规范与动态配色。
3. 响应式布局：完美适配手机、折叠屏及平板电脑。
4. 隐私安全：所有教务处凭证与课表数据均本地存储，绝不上传服务器。
